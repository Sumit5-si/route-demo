# Tech Stack

## Overview
EVoyage AI is a full-stack EV routing and charging coordination platform built with a modern web stack and a Python-based backend for route optimization and simulation logic.

## Frontend
- React 18
- TypeScript
- Vite
- Tailwind CSS
- Google Maps JavaScript API
- Leaflet
- Lucide React icons
- Progressive Web App (PWA) support

## Backend
- Python
- FastAPI
- Uvicorn
- Pydantic
- WebSockets
- Python-dotenv
- HTTPX

## Data and Cloud Services
- Supabase
- Supabase JavaScript client
- Real-time data integration
- EV station and trip data management

## Core Product Features
- EV charging route planning
- Real-time trip simulation
- Battery and charging decision logic
- Multi-EV coordination
- Station history and route comparison
- Explanations for recommended routes

## Development Tools
- VS Code
- Git / GitHub
- npm
- pip
- PostCSS and Autoprefixer

## Architecture Summary
- Frontend: React + TypeScript + Vite + Tailwind
- Backend: FastAPI + Python services
- Database / realtime services: Supabase
- Maps: Google Maps + Leaflet
- Decision engine: Python-based EV routing and battery logic

## Stack Highlights
- Fast, responsive web interface
- Real-time route and charging updates
- Scalable Python backend for decision logic
- Cloud-connected data layer for station and trip data
- User-friendly EV journey experience
